# SSC CGL 2026 GA – MCQ Book with Explanations

`SSC_CGL_2026_GA_MCQ_Book.pdf` (96 pages, 708 MCQs). Part A: 42 questions reported by candidates from SSC CGL
2026 Tier-1 shifts (memory-based, via coaching-site analyses), as MCQs with date/shift/source tags. Part B:
original practice MCQs on the static GS topics asked in 2026, plus five 25-question mock sets. Every MCQ has
the answer and an explanation. Current affairs excluded. Part B questions are not previous-year questions.

```bash
pip install reportlab pypdf
python3 build.py src SSC_CGL_2026_GA_MCQ_Book.pdf
```
