# SSC JE Mechanical – Topper-Style Concept Notes

`SSC_JE_Mechanical_Topper_Notes.pdf` (173 pages) – concept notes for SSC JE Mechanical (Paper-I Part B and
Paper-II), with formula boxes, PYQ-trend concept boxes, solved numericals (no MCQ practice), recall bank and
model answers.

The PDF is generated from the plain-text chapter sources in `src/`:

```bash
pip install reportlab pypdf matplotlib
python3 figs.py                                   # regenerate diagrams into figs/
python3 build.py src SSC_JE_Mechanical_Topper_Notes.pdf
```
