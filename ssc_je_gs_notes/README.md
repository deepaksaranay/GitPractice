# SSC JE General Awareness – Topper-Style Concept Notes

`SSC_JE_General_Awareness_Topper_Notes.pdf` (146 pages) – concept notes for the 50-mark General Awareness part
of SSC JE Paper-I (CBT-1): history, art & culture, polity, geography, economy, physics, chemistry, biology,
static GK, science & technology and computers. Includes key-fact strips, PYQ-trend concept boxes, a recall
bank and two auto-compiled appendices (key-fact sheet and PYQ concept map). No MCQs.

Build from the text sources in `src/`:

```bash
pip install reportlab pypdf
python3 build.py src SSC_JE_General_Awareness_Topper_Notes.pdf
```
