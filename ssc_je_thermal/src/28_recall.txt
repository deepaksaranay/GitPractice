## R1. Basic Thermodynamics and First Law
| Question | Answer |
| System exchanging neither mass nor energy? | Isolated system |
| System exchanging energy but not mass? | Closed system (control mass) |
| Turbine, compressor, nozzle are which systems? | Open systems (control volume) |
| Intensive property examples? | Pressure, temperature, density, specific volume |
| Extensive property examples? | Mass, volume, energy, enthalpy, entropy |
| Is the ratio of two extensive properties intensive? | Yes (e.g. specific volume = V/m) |
| Basis of temperature measurement? | Zeroth law |
| Heat and work are path or point functions? | Path functions (inexact differentials) |
| Thermodynamic properties are? | Point (state) functions – exact differentials |
| Quasi-static process means? | Infinitely slow, passes through equilibrium states |
| Work in free expansion? | Zero |
| Work in a constant-volume process? | Zero (∫p dV = 0) |
| Area under p–V curve represents? | Work (non-flow) |
| Area under T–s curve represents? | Heat (reversible) |
| First law for a cycle? | ∮δQ = ∮δW |
| First law for a process? | Q = ΔU + W |
| Internal energy of an ideal gas depends on? | Temperature only (Joule's law) |
| PMM-1 violates? | First law |
| Enthalpy definition? | H = U + pV |
| c_p − c_v for ideal gas? | R (Mayer's relation) |
| γ for monatomic / diatomic gas? | 1.67 / 1.4 |
| Universal gas constant? | 8.314 kJ/kmol·K |
| R for air? | 0.287 kJ/kg·K |
| c_p and c_v of air? | 1.005 and 0.718 kJ/kg·K |
| Isothermal process for ideal gas: ΔU? | Zero; Q = W |
| Adiabatic process: Q? | Zero; W = −ΔU |
| Polytropic index n = 0, 1, γ, ∞? | Isobaric, isothermal, adiabatic, isochoric |
| Heat transfer in polytropic process? | Q = W (γ − n)/(γ − 1) |
| Slope of adiabatic vs isothermal on p–V? | Adiabatic is γ times steeper |

| Throttling process? | Isenthalpic (h₁ = h₂), irreversible |
| Joule–Thomson coefficient? | μ = (∂T/∂p)_h; zero for ideal gas |
| Inversion temperature? | Above it, throttling heats the gas |
| Flow work? | pv – energy to push fluid across boundary |
| Steady-flow work of reversible process? | −∫v dp |

| Question | Answer |
